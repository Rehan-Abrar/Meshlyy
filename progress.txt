## 2026-04-14 Media Upload Endpoint + Cloudinary Scoping Fix

### Scope
- Implemented missing media upload signature endpoint required by production-readiness audit.
- Enforced server-side role/user folder scoping and upload-kind path whitelist.

### Files Touched
- `Backend/src/routes/media.ts`
- `Backend/src/app.ts`
- `docs/production-readiness-audit.md`

### Summary of Changes
- Added authenticated endpoint: `GET /v1/media/upload-url`.
- Endpoint behavior:
	- Requires auth context (`verifyToken` + `loadAuthContext`).
	- Whitelists `kind` values: `avatar`, `logo`, `portfolio`, `media-kit`.
	- Builds folder path server-side only as `meshlyy/{role}/{userId}/{kind}`.
	- Enforces resource-type allowlist per upload kind.
	- Returns Cloudinary signed upload payload with timestamp-based expiry semantics.
	- Returns format and max-size constraints for client-side enforcement.
- Wired route in app bootstrap via `/v1/media`.
- Updated audit finding from FAIL to PASS and removed the media endpoint gap from critical blockers.

### Verification Evidence
- Backend typecheck: `npm run typecheck` (pass)
- Authenticated smoke test against `/v1/media/upload-url?kind=media-kit`: `200`, signature present, scoped folder returned, allowed format list returned.
